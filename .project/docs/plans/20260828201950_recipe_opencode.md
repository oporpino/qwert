# Recipe opencode — Plano de implementação

> **TLDR**: criar o recipe `opencode` em `recipes/opencode/` para instalar via brew e sincronizar skills/commands de IA para `~/.config/opencode/`.

> **Spec:** sem spec — pedido direto do usuário
> **Branch:** `main`

**Arquitetura:** recipe do tipo `brew` seguindo o padrão dos demais recipes (`install.toml` + `setup.toml`). O setup espelha o recipe `claude` existente: symlink de `~/.qwert/ia/skills` e `~/.qwert/ia/commands` para o diretório de config do opencode.

**Stack:** TOML (schema de recipes do qwert).

## Restrições globais

- `install.toml` do tipo `brew` — o adapter deriva `brew install <pkg>` do `meta.pkg`; não escrever `[install]` explícito.
- `setup.toml` no formato flat com seção `[undo]` (padrão do recipe `claude`).
- Nome do diretório: `recipes/opencode/`.

### Task 1: Criar recipe opencode

**Files:**
- Create: `recipes/opencode/install.toml`
- Create: `recipes/opencode/setup.toml`

**Interfaces:**
- Consumes: schema de recipes (RecipeMeta, RecipeCheck, RecipeSetup)
- Produces: recipe `opencode` usável por `qwert use opencode`

- [ ] **Step 1: Criar `install.toml`**

```toml
[meta]
name = "opencode"
version = "1.0.0"
description = "AI coding agent for the terminal"
type = "brew"
pkg = "anomalyco/tap/opencode"

[check]
command = "opencode"
version_flag = "--version"
```

- [ ] **Step 2: Criar `setup.toml`**

```toml
to = "~/.config/opencode"
macos = [
  "ln -sfn ~/.qwert/ia/skills ~/.config/opencode/skills",
  "ln -sfn ~/.qwert/ia/commands ~/.config/opencode/commands",
]

[undo]
macos = [
  "rm -f ~/.config/opencode/skills ~/.config/opencode/commands",
]
```

- [ ] **Step 3: Validar parsing do recipe**

```bash
cargo run -- info opencode 2>/dev/null || cargo test
```

- [ ] **Step 4: Commit**

```bash
git add recipes/opencode
git commit -m "feat: opencode recipe"
```
